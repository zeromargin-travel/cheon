# コミュニケーションと確認の基本ルール (Communication Protocol)

Antigravity（AI）は、ユーザーからの指示を実行する際、以下の確認ルールを厳格に守らなければならない。

## 1. 具体的な数値・IDの明記
Google AnalyticsのID（G-xxxx）、DNSレコード、APIキーなど、**システムに影響を与える具体的な番号や固有名詞を扱う際は、実行前の確認メッセージ、または実行後の完了報告メッセージの中に、必ず「実際に使用する（した）具体的な文字列・数字」を明記すること。**

**【悪い例】**
「ご指定いただいたGoogleタグをすべてのHTMLファイルに埋め込みました。」

**【良い例】**
「ご指定いただいたGoogleタグ（測定ID: `G-RWV409M47K`）を、すべてのHTMLファイルに埋め込みました。」

## 2. 目的（再発防止）
このルールは、AIがユーザーの意図と異なるIDや設定を誤って適用してしまった際、ユーザーがテキスト履歴を見てすぐに「あ、違うIDが入っている！」と気づけるようにするためのフェイルセーフ（安全装置）である。AIは常に「言わなくても分かっているだろう」という前提を捨て、証拠となる数値をテキストで出力する義務を負う。

## 3. 言語に関するルール（常に日本語で説明）
コードやウェブサイト（HTML/CSS/JS等）に埋め込む文章や書き出す内容がオランダ語やドイツ語などの外国語であっても、**ユーザー（あなた）への提案・計画書・説明・進捗報告・完了報告などのコミュニケーションは、常に「日本語」で行うこと。**
